# Свод правил оформления и подготовки индивидуального проекта (проектной работы)

Свод составлен по материалам сайта workproekt.ru: весь текст сайта по теме разобран по разделам, очищен от меню, рекламы и интерактивных сервисов, исправлен и сведён в единые файлы. Правила даны для школьников 5–11 классов, колледжа и вуза (материалы только для начальной школы не включены).

Если у учебного заведения или руководителя есть собственные требования, сайт рекомендует следовать им; если таких требований нет, действуют правила из этого свода.

## Примечания

- Основные параметры текста (поля 30/15/20/20 мм, Times New Roman 14 pt, интервал 1,5, абзацный отступ 1,25 см, нумерация страниц со 2-й) собраны в файле [Общие требования](01_Общие_требования.md). Параметры отдельных элементов (титульный лист, содержание, паспорт, приложения, речь) указаны в их файлах.
- В исходных страницах сайта есть расхождения: объём пояснительной записки назван «до 2 страниц» и «до 1 страницы»; объём аннотации — «1 страница, в редких случаях 2» и «0,75–1 страница». В файлах сохранены оба варианта, как на сайте. Поля речи к защите: в одном месте сайта они указаны зеркально, правильные значения такие же, как в проекте (левое 3 см, правое 1,5 см).
- Порядок введения: актуальность, проблема, цель, задачи, объект, предмет, гипотеза, продукт, методы, срок, этапы, теоретическая основа, значимость, новизна, структура. Описание каждого элемента лежит в отдельном файле `10_*`.
- Из свода убраны: реклама, ссылки на онлайн-сервисы и ИИ-инструменты сайта, видео, интерактивные тесты и чек-листы, материалы для 1–4 классов.
